Deploy your copy

Clone the public repo into your Vercel account. It does not connect to the maintainer's app.

2

Add free storage

Create a free Upstash Redis database in Vercel Storage so your book list persists.

3

Set a password

Add APP_PASSWORD. Optional AI summaries work only if you add your own AI key.

What stays private

  • Your books live in your own Upstash Redis database.
  • Your password is stored only in your browser.
  • Your AI provider key is never bundled into the frontend.

What stays optional

  • No AI key is needed for manual entry or Open Library search.
  • Push reminders need VAPID keys only if you turn them on.
  • Backups are disabled until you opt in.

Open source on GitHub. Built for personal reading goals, not a hosted service.
