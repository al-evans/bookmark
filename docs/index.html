Bookmark

Track books, reading progress, finished stats, and reminders in your own Vercel project. AI is optional and only uses your own key.

Deploy with Vercel Read setup guide

What costs money?

  • Hosting can use Vercel Hobby.
  • Storage can use the free Upstash Redis tier.
  • AI stays off unless you add your own provider key.
  • No maintainer service, database, or AI key is shared.
1

Deploy your copy

Clone the public repo into your Vercel account. It does not connect to the maintainer's app.

2

Add free storage

Create a free Upstash Redis database in Vercel Storage so your book list persists.

3

Set a password

Add APP_PASSWORD. Optional AI summaries work only if you add your own AI key.
